# Koalas da Vinci – Vokabeltrainer

Englisch-Vokabeltrainer für die 5. Klasse. Die App läuft komplett im Browser; die Vokabeln werden nur auf dem jeweiligen Gerät gespeichert (Export/Import über „Verwalten → Sichern & übertragen“).

Installation: Die Seite im Browser öffnen. iPhone: Teilen → „Zum Home-Bildschirm“. Android (Chrome): Menü → „App installieren“.
