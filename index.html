📋 Aus Text einfügen

Kopiere eine Vokabelliste aus einem PDF, einer Webseite, einer Tabelle oder einer Nachricht und füge sie hier ein. Jede Zeile wird als eine Vokabel erkannt, z. B. „apple – Apfel“, „apple: Apfel“ oder „apple[Tab]Apfel“.

📷 Vokabeln per Foto

Wähle ein Foto einer Vokabelliste aus. Auf dem Smartphone öffnet sich die Galerie oder die Kamera. Die Erkennung läuft komplett im Browser; das Foto wird nicht hochgeladen.
